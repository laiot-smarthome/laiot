# База знаний

Раздел `/knowledge-base` читает те же Markdown-файлы, что и агенты:
`docs/**/*.md`. Отдельной таблицы в БД нет — источник истины остаётся в
файлах, а индекс строится на запрос.

Индекс не отделяет версии runtime: в docs/** остаются и документы alpha.
Для нового приложения начинайте с LaIOT/README; старый текст с похожей
темой не означает, что описанный им маршрут или команда поддерживаются.

## 1. Источники и front matter

Сканируется `docs/**/*.md`; служебные и скрытые файлы пропускаются. Новый
файл появляется в списке сразу, пересобирать ничего не нужно.

Используются ключи front matter:

| Ключ | Смысл |
| --- | --- |
| `title` | заголовок карточки и статьи |
| `description` | описание в списке |
| `category` | ключ категории (`core`, `dev`, `todo`, …) |
| `category_label` | человеческое имя категории |
| `audience` | `user`, `agent` или `user, agent` |
| `tags` | метки через запятую, участвуют в поиске |
| `order` | порядок внутри категории |

Если ключа нет, заголовок берётся из первого `#`, описание — из первого
абзаца, категория — из первого каталога (`laiot`, `todo`), аудитория —
из front matter, иначе считается общей.

## 2. Поиск и категории

Поиск идёт по заголовку, описанию, меткам и полному тексту: все слова запроса
должны встретиться. Категории и количество материалов считаются по индексу.
Фильтр по категории и поиск можно совмещать.

Каталог использует `knowledge-catalog` (Yoyo): поиск с задержкой 300 мс,
выбор категории и сброс обновляют результаты через `/yoyo` без перезагрузки.
Категории со счётчиками расположены слева, на телефоне — в прокручиваемой
строке над карточками. Счётчики категорий относятся ко всему индексу;
«Найдено» показывает число результатов с учётом обоих фильтров.

Карточки собраны на `x-md.card`, поля и действия — на `x-md.input` и
`x-md.button`. Дата изменения файла показана как `28.10.2026 14:30`,
без запятой. В статье оглавление закреплено справа на ПК и расположено
перед текстом на телефоне; его можно свернуть. Кнопка «К результатам поиска»
возвращает в каталог с запросом и выбранной категорией.

## 3. Рендер Markdown

Блоки кода показывают кнопку копирования: в буфер попадает только текст
блока. Категория `console` («Консольные команды») содержит полный
[справочник CLI](console.md), который сверяется с реестром тестом.

Используется `league/commonmark` (GFM: заголовки, списки, таблицы, код,
цитаты, задачи). Настройки безопасности:

- `html_input=strip` — сырой HTML из документа не исполняется;
- `allow_unsafe_links=false` — `javascript:` и подобные схемы отбрасываются;
- относительные ссылки на другие `.md` переписываются в
  `/knowledge-base/<id>`;
- картинки и прочие относительные файлы — в `/docs/...`;
- заголовки `h2`/`h3` получают id, по ним строится оглавление статьи.

Первый `#`-заголовок, совпадающий с `title`, из текста убирается: он уже
показан в шапке страницы.

## 4. Код

| Слой | Файл |
| --- | --- |
| Сервис индекса и поиска | `app/Services/Docs/KnowledgeBase.php` |
| Markdown и ссылки | `app/Services/Docs/MarkdownRenderer.php` |
| Ядровой раздел | `app/Http/Controllers/Core/KnowledgeBaseController.php` + `resources/views/pages/knowledge_base/` |
| Интерактивный каталог | `app/Yoyo/KnowledgeCatalog.php` + `resources/views/yoyo/knowledge-catalog.blade.php` |
| Оформление каталога и чтения | `resources/css/knowledge-base.css`, входит в общий бандл |

Собственных таблиц нет; старые `modules/knowledge_base`,
`templates/knowledge_base` и page-ассеты удалены вместе с alpha-runtime.
Ветка `alpha` хранит прежнюю реализацию; новый код её не использует.

## 5. Ограничения

- документация SDK-модулей в `modules/**/docs` пока не добавляется к индексу
  автоматически; текущий источник — корневой `docs/**`;
- нет редактирования/загрузки файлов из админки — источник только файлы;
- нет кэша между запросами: индекс и поиск читают файлы при каждом запросе
  (сейчас это десятки документов);
- сырой HTML не поддерживается намеренно.

## 6. Проверка

```bash
php vendor/phpunit/phpunit/phpunit --filter KnowledgeBaseTest
```

Тест проверяет front matter, категории, аудиторию, безопасный рендер, ссылки,
оглавление, поиск, защиту от `..` и ядровые страницы базы знаний.
Дополнительно проверяются совместная фильтрация через Yoyo, пустая выдача,
сброс фильтров, формат даты и сохранение контекста при возврате из статьи.
