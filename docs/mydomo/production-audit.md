# Аудит админки и ядра, 2026-10-29

Проверен текущий MyDoMo в Windows: код, изолированные SQLite-тесты и
локальный браузерный стенд без рабочего bootstrap, `.env` и внешних сервисов.
Это результат конкретного прохода, а не гарантия отсутствия всех ошибок.

## Исправлено

| Область | Причина и результат |
| --- | --- |
| Главная | Float маскота сужал заголовок и собирал содержимое слева. Заголовок получил свободную колонку, маскот расположен справа, состояние и действия — отдельной общей строкой. |
| Цепочки событий | Соединители зависели от фиксированных отступов и высот. SVG теперь соединяет фактические центры узлов и метки веток; переносы, раскрытие и изменение размера вызывают пересчёт. |
| Подсветка цепочки | Наведение и фокус выделяют путь от корня до выбранного шага; фоновые ветки остаются нейтральными. Управление раскрытием ограничено своей схемой. Кнопки больше не скрыты от скринридера через `aria-hidden` родителя. |
| Классы | Состояние веток сохраняется отдельно для пользователей; поиск временно раскрывает совпадения, сброс возвращает прежнее состояние. Счётчик показывает видимые классы. |
| Производительность дерева | Индексы и результаты фильтрации не строятся заново для каждой строки. Убран произвольный предел 100 предков; от циклов защищает множество посещённых ID. |
| Контроллеры | Сборка дерева и статистики вынесена в `Panel\ClassCatalog`, четыре копии сообщения переименования заменены `Panel\RenameNotice`. Классы читаются один раз, счётчики объектов берутся из того же снимка. |
| Диагностика | Сбои чтения объектов, счётчиков, подписок и состояния локаций больше не превращаются в ложные пустые списки. Сбой пересчёта таймера комнаты записывается в журнал и явно показывается через Notify. |
| Меню действий | Общий `x-md.dropdown` использует нативный popover: меню не обрезается таблицей и не уходит за края экрана. Добавлены стрелки, Home/End и возврат фокуса. |
| Мобильная панель | Дерево помещается без горизонтальной прокрутки; быстрые действия доступны в меню. Поиск шапки открывается кнопкой, сенсорные цели увеличены. На экране уже 360 px выход остаётся в боковом меню. |
| Поиск | Новый ввод, очистка и закрытие сразу отменяют старый запрос. Запоздалый ответ не восстанавливает старую выдачу. Enter не открывает скрытый результат. |
| Диалоги | Закрытый поиск исключён из Tab; панели удерживают фокус, пропуская скрытые, disabled и inert-контролы. Модальный фон не прокручивается. |
| Тема | Повреждённая cookie больше не вызывает исключение `decodeURIComponent`, прерывающее запуск админки. Исправлены также вход, установщик и страницы ошибок. |
| Значения свойств | До записи проверяются массив, допустимые ID и строковые значения. Ошибка сохраняет черновик, вкладку и сообщения полей. Весь пакет значений, шагов выполнения и заданий событий откатывается при отказе. |
| Результаты операций | Создание, сохранение и удаление классов, объектов, свойств, методов, сценариев и локаций подтверждаются одноразовым Notify. |
| HTTP | Массив вместо скалярного входного поля возвращает 400 `bad_request` с request ID и security headers, без выдачи внутреннего исключения. |
| API-токены | Выпуск требует существующего неудалённого владельца. Удалённый или отсутствующий владелец не проходит аутентификацию, `last_used_at` такого токена не обновляется. Обычные пользователи сохраняют право владеть токенами. |
| Журнал ошибок | Самодельный список заменён общим `x-md.table`, включая повторы в деталях. Добавлены отдельные колонки, мобильное расположение метаданных и читаемые длинные сообщения. Поиск получил недостающий Yoyo-триггер запроса и реагирует на вставку/очистку. Request ID группы больше не перезаписывается старым повтором; счётчик повторов учитывает предел 100 отображённых строк. |
| Размеры контролов | Поиск и фильтры таблиц используют общую высоту 36 px; на телефоне поля, селекты и кнопки тулбара — минимум 44 px. |
| Подтверждения | Модалки имеют варианты ширины sm/md/lg/xl; подтверждение — md, 500 × 240 px с ограничением по экрану. Длинный текст прокручивается внутри; заголовок и кнопка закрытия не выталкивают границы. Примеры размеров и длинного текста добавлены в UI Kit. |

## Проверка и границы

- `composer check` — lint, CS-Fixer dry-run и PHPStan без ошибок;
  итоговый PHPUnit: 479 тестов, 2819 проверок, 7 Linux-only пропусков на
  Windows. Набор включает параллельно добавленные тесты уведомлений и
  диагностических страниц; первый проход аудита содержал 450 тестов.
- `npm run test:ui` — 9 тестов прошли; `node --check` изменённых JS и
  `npm run build` выполнены успешно.
- `php tests/docs_quality_smoke.php` — 764 проверки, 41 файл;
  структура и ссылки документации проверены.

Регрессии покрывают восстановление дерева, глубину больше 100, повреждённый
storage, отмену запросов, клавиатурный фокус, геометрию цепочек, повреждённую
тему, неверный пакет значений и отказ второго задания очереди. Отдельно
проверены 400 HTML/JSON и токены удалённого владельца.

Браузерный стенд использует SQLite в памяти, ArraySession и array-кэш.
Проверены светлая и тёмная темы, дерево классов, меню у нижней строки,
мобильный поиск, форма свойств, пользователи, главная и цепочка UI Kit.
У цепочки проверены шесть соединений и пять выделенных участков пути к
конечному свойству; мобильная схема помещается в свою колонку.

Дополнительно проверены таблицы `/errors`, переход в разбор и обратно,
поиск после вставки текста и одинаковая высота фильтров. У модалок измерены
ширины 300/500/800/1140 px. Короткое и длинное подтверждения сохраняют
500 × 240 px на десктопе и ограниченную экраном ширину при той же высоте
на 390 и 320 px. Длинный текст прокручивается внутри; настоящее удаление
в браузере не выполнялось, диалог закрыт отменой. Адресный набор компонентов,
журнала ошибок и UI Kit: 12 тестов, 137 проверок прошли.

Перед выпуском остаётся отдельный прогон на целевой Ubuntu с MariaDB,
Redis, pcntl и systemd, а также с реальными MQTT/Zigbee-устройствами.
На Windows Linux-проверки пропускаются. У сборки остаются предупреждения
Vite о крупных JS-файлах; отдельное разбиение Tabulator и других библиотек
в этот проход не включено. Остальные архитектурные ограничения перечислены
в [limitations.md](limitations.md).
