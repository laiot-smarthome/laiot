# MyDoMo — правила для агентов

## 1. Что читать первым

1. [README MyDoMo](README.md) — статус.
2. [Архитектура](architecture.md) — слои и сервисы.
3. [Функции](functions.md) — публичный API и обёртки.
4. [Мастер-план](../todo/mydomo.md) — этапы и текущий прогресс.
5. [Модули](modules.md) — только когда core-gate закрыт.

## 2. Порядок работ

- Сначала **core-gate**, затем модули по одному.
- Не делать «горизонтальные» куски по всем модулям.
- Один модуль = новый контроллер, `modules/core/<id>`, `ModuleDb`,
  Blade-страница в alpha-shell, удаление старого кода, тесты, ручная проверка.
- Если для модуля не хватает ядра — сначала добавляется недостающий сервис
  в ядро и документируется, потом модуль.

## 3. Границы

- `alpha` — совместимая ветка; её API не является контрактом MyDoMo.
- Новый код не использует `$db`, `SQLSelect*`, `mysqli_*`, `PDO`, `eval`,
  shell и прямые пути ядра.
- Модули — только через `ModuleDb`/`ModuleBus`; чужие таблицы запрещены.
- Внешний вид — только alpha; новый layout/CSS не создаём.
- Core-модули в `modules/core` не удаляются и не отключаются.

### 3.1. Чистый лист (обязательно)

- никаких редиректов со старых URL на новые;
- никаких legacy-таблиц, uppercase-колонок и адаптеров под старую схему;
- после переноса модуля старые `modules/<id>`, `templates/<id>`, `.inc.php`
  удаляются, а не остаются «на всякий случай»;
- `alpha` — отдельная архивная ветка, а не runtime-совместимость MyDoMo;
- если нужен импорт старых данных — это отдельный инструмент, а не чтение
  старой таблицы из нового кода.

## 4. Документирование

Публичный метод/команда/обёртка считается недоделанной, пока не описана:

- в [functions.md](functions.md) — сигнатура, возврат, пример;
- в [architecture.md](architecture.md) — если меняется слой/поток;
- в [мастер-плане](../todo/mydomo.md) — чекбокс и следующий шаг.

Не документируй планируемое как работающее. Если что-то не проверено
(например, live Redis), так и напиши.

## 5. Проверки

```bash
composer check
php tests/docs_quality_smoke.php
php bin/mydomo about
php dev_server.php --host=127.0.0.1 --port=8080
```

Docker — только по отдельной просьбе или для Linux-only проверки.
Не пересобирать Docker после каждого коммита.

## 6. Git

- Одна ветка — `MyDoMo`.
- Коммит содержит код + документацию + чекбокс плана.
- Удалённый legacy-код фиксируется в журнале `docs/todo/mydomo.md`.
- Сообщение коммита — по-русски, коротко.
